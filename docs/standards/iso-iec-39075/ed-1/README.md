# ISO/IEC 39075:2024 electronic inserts (edition 1)

These six files are the official electronic inserts of ISO/IEC 39075:2024 (GQL), published by ISO at <https://standards.iso.org/iso-iec/39075/ed-1/en/>. They were downloaded on 2026-10-02 (server `Last-Modified`: 2024-03-23) and are stored **unmodified**.

They are a supplementary source for GQLSTATUS conditions, feature identifiers and implementation-defined items. The trusted reference for GQL syntax is `opengql/grammar` (<https://github.com/opengql/grammar>), not these files.

| File | Content |
|---|---|
| `ISO_IEC_39075(en).bnf.txt` | The GQL grammar in BNF (814 productions). |
| `ISO_IEC_39075(en).bnf.xml` | The same grammar in XML. |
| `ISO_IEC_39075(en)-conditions.xml` | GQLSTATUS condition classes and subclasses. |
| `ISO_IEC_39075(en)-features.xml` | Optional feature identifiers. |
| `ISO_IEC_39075(en)-implementation-defined.xml` | Implementation-defined items. |
| `ISO_IEC_39075(en)-implementation-dependent.xml` | Implementation-dependent items. |
