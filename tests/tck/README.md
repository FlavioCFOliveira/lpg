# Conformance scenarios

The scenarios that lpg's conformance runner (`src/tck/`, rmp #52) runs through the public API (TS-30 Semantics). Run them with `cargo nextest run -p lpg -E 'test(/^tck::/)'`.

## Contents

| Path | What it is | Licence and attribution |
|---|---|---|
| `opengql-tck/` | The 8 feature files of opengql/tck @ `e0700a7` (<https://github.com/opengql/tck>) that hold a selected scenario, and its `data/graphs/` | Apache-2.0: `opengql-tck/LICENSE`, `opengql-tck/NOTICE.md`, unchanged |
| `opencypher/` | The 41 feature files of the openCypher TCK @ `677cbaf` (<https://github.com/opencypher/openCypher>, `tck/features/`) that hold a selected scenario | Apache-2.0: `opencypher/LICENSE`, `opencypher/NOTICE`, unchanged |
| `lpg/features/approved-features.feature` | lpg's own scenarios for the approved optional features that no selected scenario exercises | MIT, lpg project |
| `lpg/features/gql-compat/` | The selected gql-compat @ `9de1991` cases (<https://github.com/tamnd/gql-compat>), translated into scenarios by `docs/evidence/lab-sprint-3/gqlcompat_translate.py` (user decision 2026-10-08, rmp #37) | Apache-2.0: `lpg/features/gql-compat/LICENSE-gql-compat`; each file names its source suite file and each scenario its case |
| `selection.tsv` | One line per scenario instance of the vendored files and per gql-compat case: its state under the TS-30 selection rule and the unapproved codes that exclude it | Generated by `docs/evidence/lab-sprint-3/tck_manifest.py` |
| `clauses.tsv` | The `GQL.g4` subclause each vendored feature file exercises | lpg project |

The vendored feature files are byte-identical to their upstream commits. Their scenarios that the selection rule does not select stay in the files and are skipped with the reason `selection.tsv` gives.

## Regenerate

With the clones of the three artefacts and of opengql/grammar @ `16ea71b` under `/tmp`, a JDK, PyYAML and the ANTLR 4.13.2 tool jar (as in `docs/evidence/planning/round-s/README.md`):

```
python3 -I -B docs/evidence/lab-sprint-3/tck_manifest.py /tmp/opengql-grammar/GQL.g4 \
  "docs/standards/iso-iec-39075/ed-1/ISO_IEC_39075(en)-features.xml" \
  docs/evidence/planning/round-s/anchors.tsv <antlr-4.13.2-complete.jar> $WORK \
  /tmp/opengql-tck /tmp/opencypher /tmp/gql-compat tests/tck/selection.tsv
python3 -I -B docs/evidence/lab-sprint-3/gqlcompat_translate.py /tmp/gql-compat \
  tests/tck/selection.tsv tools/gql-oracle/grammar/GQL.g4 tests/tck/lpg/features/gql-compat
```
